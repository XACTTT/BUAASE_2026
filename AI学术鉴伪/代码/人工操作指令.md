## 三、前端加载不出来的排查步骤

### 步骤1：检查后端是否可达
```bash
curl -s -o /dev/null -w "%{http_code}" http://116.63.14.7/api/
# 期望返回 200 或 404（只要不是超时/连接拒绝即可）
```

### 步骤2：检查前端 dev server 是否运行
```bash
ps aux | grep vite | grep -v grep
# 应该看到两个 vite 进程（用户端 5173、管理端 5174）
```

### 步骤3：检查是否有残留的 .js 文件干扰 .ts 加载
```bash
cd /home/g203/ruangong-5-19/BUAASE_2026/AI学术鉴伪/代码/前端/前端用户端
find src/ -name "*.js" | while read f; do
  ts="${f%.js}.ts"; vue="${f%.js}.vue"
  if [ -f "$ts" ] || [ -f "$vue" ]; then echo "STALE: $f"; fi
done
```
如果有输出，删除这些 .js 文件：
```bash
find src/ -name "*.js" -delete
```

### 步骤4：重启前端 dev server
```bash
# 先停掉
kill $(lsof -t -i:5173) 2>/dev/null
kill $(lsof -t -i:5174) 2>/dev/null

# 再启动（分别在两个终端）
cd /home/g203/ruangong-5-19/BUAASE_2026/AI学术鉴伪/代码/前端/前端用户端 && npm run dev
cd /home/g203/ruangong-5-19/BUAASE_2026/AI学术鉴伪/代码/前端/前端管理端 && npm run dev
```

### 步骤5：浏览器端操作
1. 打开 http://127.0.0.1:5173（用户端）或 http://127.0.0.1:5174（管理端）
2. 按 `Ctrl+Shift+R` 强制刷新（清除缓存）
3. 按 `F12` 打开开发者工具 → Console 查看错误
4. 如果看到 localStorage 相关问题，在 Console 中执行：
```javascript
localStorage.clear()
location.reload()
```

### 步骤6：检查端口是否被占用
```bash
lsof -i:5173
lsof -i:5174
lsof -i:8000
```

## 五、Git 操作

### 当前分支
```bash
git branch
# 当前在 fix/detection-and-review-overhaul
```

### 查看修改记录
```bash
git log --oneline -10
```

### 回退到某个提交
```bash
git log --oneline           # 找到要回退的 commit hash
git reset --soft <hash>     # 保留修改，只回退提交
git reset --hard <hash>     # 丢弃所有修改（危险）
```

### 查看某次提交改了什么
```bash
git show <hash> --stat      # 文件列表
git show <hash> -- <path>   # 某文件的具体改动
```

## 六、常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| 页面空白 | 残留 .js 文件覆盖 .ts | `find src/ -name "*.js" -delete`，重启 dev server |
| 页面空白 | 后端不可达 | 检查 116.63.14.7 是否在线 |
| 登录后空白 | localStorage 中 token 过期 | 浏览器 Console 执行 `localStorage.clear()` |
| 图片不显示 | /media 代理未配置 | 用户端 vite.config.mts 应有 `/media` 代理规则 |
| 检测结果页白屏 | task_type 未识别 | 检查 step/[id].vue 的路由逻辑 |
| 提交审核报错 | 文本审核格式不匹配 | 检查 submitReview 的 text_reviews 字段 |
| WebSocket 断开 | 后端 Channels 未运行 | 启动 daphne 或检查 Redis |
